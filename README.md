# マイドンラボ

GitHub のリリースをそのまま一覧にして見せるサイトです。サーバーもデータベースも使いません。

## 3段の分け方
| 段 | 何で決まるか | 例 |
|---|---|---|
| 1段目（大分類・タブ） | 本文の `カテゴリ:` | コラボ |
| 2段目（小分類・ボタン） | リリースのタイトル | ボーカル系 |
| 3段目（マイドン本体・カード） | 添付した「同じ名前の画像＋zip」1組 | 歌姫A.png ＋ 歌姫A.zip |

- 小分類が1つしかない大分類は、ボタンを出さずにそのまま中身を表示します
- 1体に画像が何枚もある時は `歌姫A_2.png` のように番号を付けます
- zip の名前に `_60fps` のように入れると、その1体だけ fps を変えられます（表示名からは消えます）
- 名前がそろっていないリリースは、リリース全体で1体として表示されます
- 1体だけの投稿は、ファイル名に関係なくリリースのタイトルがマイドンの名前になります

## 投稿ツール（Windows・おすすめ）
`tools` フォルダの **MydonUploader.bat** をダブルクリックすると、投稿用の画面が開きます。

**最初の1回だけ：トークンを作る**
1. GitHub 右上のアイコン → **Settings** → 左下の **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
2. **Repository access** で **Only select repositories** → `mydonlabo` を選ぶ
3. **Permissions** の **Contents** を **Read and write** にする
4. **Generate token** を押して、出てきた文字列をコピー
5. ツールの **トークン設定** に貼り付け（このPCのこのユーザーだけが読める形で保存されます）

**投稿のしかた**
1. 「新しい小分類を作る」か「今ある小分類に追加」を選ぶ
2. 大分類・小分類の名前・タグなどを入れる（追加の時は不要）
3. 画像と zip を一覧にドラッグ＆ドロップするか「＋ マイドン追加」で選び、マイドンの名前を入れる
4. **GitHub に投稿する** を押す

**一括投稿（一覧から）**
右上の **一括投稿（一覧）…** で、`大分類,小分類,名前,リンク,サムネ,メモ` の列を持つ CSV を選ぶと、リンク（ギガファイル便など）を順番にダウンロードして投稿します。
- 名前が空なら zip のファイル名を使います
- zip の中に `Config.json` の入ったフォルダが複数あれば、1フォルダ＝1体として zip を分けて上げます（名前はフォルダ名）
- サムネの数とマイドンの数が同じなら順番に対応させ、違う時やサムネが無い時は各フォルダの `balloon_broke` の最後の画像（無ければ `normal` の最初の画像）を使います
- 同じ大分類・小分類の行は1つの小分類にまとまります。CSV を Excel で書き換えれば、投稿前に振り分けを変えられます
- 失敗したリンクは、CSV と同じ場所の「一括投稿の結果_日時.txt」に残ります

**小分類をまとめる**
右上の **小分類をまとめる…** で、まとめたい小分類を2つ以上チェックして名前を入れると、一番上の小分類に中身を移して1つにします（ダウンロード・名前の付け直し・上げ直しは自動）。全部終わってから元の小分類を消すので、途中で止まっても元は残ります。

ファイル名は自動で `m01.png` `m01.zip` のように付け直され、マイドンの名前は本文の `名前 m01: 天海春香` という行に保存されます（サイトはこの名前で表示します）。

## 投稿のしかた（GitHub の画面から直接）
1. サイトのURLの最後に `#admin` を付けて開き（例：`https://miudaa.github.io/mydonlabo/#admin`）、右上の **＋ 投稿** を押す（タグ名と本文の「カテゴリ: 」が自動で入った作成画面が開きます）
   - `#admin` を付けた時だけボタンが出ます。ブックマークしておくと便利です
2. **Release title** に小分類の名前を書く（例：ボーカル系）
3. 本文の各項目を埋め、その下に説明を書く（説明は省略OK）
   - `カテゴリ:` タブ分けに使う名前
   - `タグ:` 詳細検索の「タグ指定」で使う。複数は `,` か `、` かスペースで区切る（例：`和風, 夏`）
   - `fps:` 詳細検索の fps 絞り込みで使う（最初は 60 が入っています）
   - `カラー:` default 以外ならその色名を書く（詳細検索で「default / その他」に分かれます）
   - `シミュレーター:` 対応シミュレーター（最初は taikonauts。書かなかった投稿も taikonauts 扱い）
   - 使わない項目は空のままでOK
4. マイドンの画像と zip を、1体ごとに同じ名前で添付（例：`歌姫A.png` と `歌姫A.zip`。何組でもOK、1ファイル2GiB未満）
5. **Publish release** を押す → サイトに載ります（サイトを開いている場合は再読み込み）

本文の例：
```
カテゴリ: 回転
タグ: y軸, 自転
fps: 60
カラー: default
シミュレーター: taikonauts
y軸回転どんちゃん
```

- GitHub から直接作る場合は、タグ名を投稿ごとに必ず別の名前にして下さい（カテゴリ名をタグにしない）
- 編集・削除はリリース側で行えば、サイトにも反映されます
- カテゴリを書かなかった投稿は「その他」に入ります
- タブの並び順は `index.html` の `CATEGORY_ORDER` で指定できます

## 管理者の追加
**Settings → Collaborators → Add people** で GitHub のユーザーネームを追加すると、その人もリリースを作れるようになります。

## ブクマ
ログイン不要で、見る人それぞれのブラウザに保存されます（端末ごと）。
