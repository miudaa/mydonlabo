# マイドン置き場

GitHub のリリースをそのまま一覧にして見せるサイトです。サーバーもデータベースも使いません。

## 投稿のしかた
1. このリポジトリの **Releases → Draft a new release** を開く
2. **Choose a tag** で新しいタグ名を入れる（例：`matsuri-2026`。投稿ごとに別の名前）
3. **Release title** に投稿名を書く
4. 本文の1行目に `カテゴリ: イベント` のようにカテゴリを書き、2行目から説明を書く（説明は省略OK）
5. マイドンの画像（png / jpg / webp など、複数OK）と zip（複数OK、1ファイル2GiB未満）を添付
6. **Publish release** を押す → サイトに載ります（最大10分ほどキャッシュが残ることがあります）

本文の例：
```
カテゴリ；回転
y軸回転どんちゃん
```

- 編集・削除はリリース側で行えば、サイトにも反映されます
- カテゴリを書かなかった投稿は「その他」に入ります
- タブの並び順は `index.html` の `CATEGORY_ORDER` で指定できます

## 管理者の追加
**Settings → Collaborators → Add people** で GitHub のユーザーネームを追加すると、その人もリリースを作れるようになります。

## ブクマ
ログイン不要で、見る人それぞれのブラウザに保存されます（端末ごと）。
